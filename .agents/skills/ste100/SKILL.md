# STE100 writing style

Use the standard level by default. In this repository, `AGENTS.md` applies the standard style to every Codex session. Read [rules.md](rules.md) for the full rules and examples when drafting or revising prose.

Keep the meaning, requirements, conditions, exceptions, and uncertainty of the source. Do not use the fixed ASD-STE100 vocabulary. This skill does not claim compliance with ASD-STE100.

Follow project instructions and glossaries when they define terms or style. Do not rewrite code, identifiers, file paths, CLI commands, quoted text, proper nouns, or defined project terms. Write code, commit messages, and security warnings in normal style.
